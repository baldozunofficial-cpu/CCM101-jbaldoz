AWS Research – Amazon Web Services

Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It allows users and businesses to store data, run applications, use virtual computers, and access many other services through the internet.



AWS is one of the largest cloud platforms in the world and provides services for businesses, schools, startups, and large organizations. (Amazon Web Services, Inc.)

Global Infrastructure

AWS has data centers around the world organized into:



Regions – large geographic areas where AWS has cloud infrastructure.

Availability Zones (AZs) – separate locations within a Region that help keep applications available.

Edge Locations – locations closer to users that help deliver content faster.



AWS Regions are designed to be separate from each other, while Availability Zones within a Region are connected by fast and reliable networks. Using multiple Availability Zones can help protect applications if one location has a problem. (AWS Documentation)

Cloud Management Console

The AWS Management Console is a website used to manage AWS services. It allows users to:



Manage services – create and control cloud resources.

Choose Regions – select where resources will run.

Monitor usage – check resources and service activity.

Manage billing – view and monitor cloud costs.

Manage users and security – control access to AWS resources.



The console provides access to more than 200 AWS services through one web interface. (Amazon Web Services, Inc.)

Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual computers that can run websites, applications, and other programs.

Amazon S3

Amazon Simple Storage Service (S3) is used to store files such as photos, videos, documents, and backups.

Amazon RDS

Amazon Relational Database Service (RDS) makes it easier to create and manage databases without handling all the database server maintenance yourself.

Amazon EKS

Amazon Elastic Kubernetes Service (EKS) is used to run and manage applications using Kubernetes and containers.

Three Advantages

Large Range of Services – AWS provides many different cloud services for computing, storage, databases, networking, AI, and more. (Amazon Web Services, Inc.)

Global Infrastructure – AWS has many Regions and Availability Zones around the world, allowing businesses to serve customers in different locations. (Amazon Web Services, Inc.)

Scalability and Flexibility – Businesses can increase or decrease their cloud resources based on their needs.
