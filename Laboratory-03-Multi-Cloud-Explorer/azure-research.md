# Microsoft Azure Research

## Brief Overview

**Microsoft Azure** is Microsoft's cloud computing platform. It allows users and businesses to **store data, run applications, use virtual computers, and access many cloud services through the internet**. Azure is also widely used for **AI, databases, analytics, and business applications**. ([Microsoft Azure][1])

## Global Infrastructure

Azure has data centers around the world organized into:

* **Regions** – geographic areas containing Azure data centers.
* **Availability Zones** – separate locations within a region that help keep applications running if one location has a problem.
* **Geographies** – areas containing one or more regions, often used for data residency and legal requirements. ([Microsoft Azure][2])

Azure currently has **80+ regions and 500+ data centers**, giving businesses many locations to choose from. ([Microsoft Azure][3])

## Cloud Management Console

The **Azure Portal** is the website used to manage Azure resources. Users can:

* Create and manage cloud services
* Manage virtual machines and databases
* Monitor resources
* Check costs and billing
* Manage users and permissions
* Choose Azure regions

The portal also helps users organize and manage their cloud resources in one place. ([Microsoft Azure][4])

## Four Core Services

| Service                            | Purpose                           |
| ---------------------------------- | --------------------------------- |
| **Azure Virtual Machines**         | Runs virtual computers            |
| **Azure Blob Storage**             | Stores files and data             |
| **Azure SQL Database**             | Manages relational databases      |
| **Azure Kubernetes Service (AKS)** | Runs container-based applications |

### Azure Virtual Machines

Provides virtual computers that can run **websites, applications, and other programs**.

### Azure Blob Storage

Stores different types of files such as **images, videos, documents, and backups**.

### Azure SQL Database

A managed database service used to **store and organize information** without having to manage the physical database server.

### Azure Kubernetes Service (AKS)

**AKS** helps users run and manage applications that use **containers and Kubernetes**.

## Three Advantages

1. **Strong Microsoft Integration** – Azure works well with Microsoft products and business tools.
2. **Large Global Infrastructure** – Azure has many regions around the world, helping businesses reach users in different locations. ([Microsoft Azure][3])
3. **Strong Security and Reliability** – Azure provides security, backup, and high-availability features for business applications. ([Microsoft Azure][1])

## Typical Enterprise Uses

Azure is commonly used for:

* **Business applications**
* **AI and machine learning**
* **Data analytics**
* **Websites and cloud applications**
* **Database management**
* **File storage and backup**
* **Enterprise and Microsoft-based systems**
