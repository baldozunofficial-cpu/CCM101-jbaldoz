# GCP Research – Google Cloud Platform
## Brief Overview
Google Cloud Platform (GCP) is Google's cloud computing platform, publicly launched in 2011. GCP runs on the same infrastructure that powers Google Search, YouTube, and Gmail, and is especially recognized for its strengths in data analytics, machine learning/AI, and Kubernetes — the container orchestration technology Google originally created.
 
## Global Infrastructure
GCP infrastructure is organized into:
- **Regions** – independent geographic areas made up of multiple zones.
- **Zones** – isolated locations within a region where resources are deployed.
- **Google's Private Global Network** – GCP is unique in routing much of its traffic over Google's own private fiber network rather than the public internet, improving speed and reliability.
GCP has fewer regions than AWS or Azure but focuses on high-performance connectivity between them.
 
## Cloud Management Console
The **Google Cloud Console** is the web-based interface for managing GCP resources. It includes:
- Project-based organization of resources (rather than account-wide)
- Cloud Identity and Access Management (IAM) for permissions
- Cloud Billing reports and budget alerts
- Cloud Shell, a free browser-based terminal with preloaded tools
- Deployment Manager / Terraform integration for infrastructure as code
## Four (4) Core Services
| Service | Category | Purpose |
|---|---|---|
| **Compute Engine** | Compute | Scalable virtual machines |
| **Cloud Storage** | Storage | Object storage for any amount of data |
| **Cloud SQL** | Database | Managed relational database service |
| **Google Kubernetes Engine (GKE)** | Container Orchestration | Managed Kubernetes for deploying containerized apps |
 
## Three (3) Advantages
1. **Leader in AI/ML and data analytics** – Tools like BigQuery, Vertex AI, and TensorFlow give GCP an edge for data-heavy and AI-driven workloads.
2. **Best-in-class Kubernetes support** – As the creator of Kubernetes, Google offers the most mature managed Kubernetes experience (GKE).
3. **High-performance global network** – Google's private backbone network delivers fast, reliable connectivity between regions and to end users.
## Typical Enterprise Use Cases
- Big data analytics and business intelligence (BigQuery)
- Machine learning and AI application development
- Cloud-native applications built with containers and Kubernetes
- Media, gaming, and streaming workloads needing high throughput
- Startups and research organizations focused on data science
