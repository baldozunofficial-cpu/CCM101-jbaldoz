## Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** offers the broadest range of cloud services. It provides many options for computing, storage, databases, networking, security, AI, and other business needs.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** provides the best integration with Microsoft technologies. It works well with products such as Windows Server, Microsoft 365, Active Directory, and other Microsoft business tools.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud** is especially strong in AI, data analytics, and Kubernetes. Google created Kubernetes and provides **GKE**, while services such as **Vertex AI** support AI and machine learning development.

### 4. Which cloud platform would you personally choose and why?

I would choose **Google Cloud** because it has strong AI, data analytics, and Kubernetes services. It is also suitable for students and organizations that want to learn modern cloud technologies.
