# Cloud Platform Recommendations

## Client A – Startup Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is a good choice because it offers many services and flexible pricing options for a startup with a limited budget. It can easily scale as the mobile application gains more users. AWS also provides many tools for application development and deployment.

**Possible services:**

* **Amazon EC2** – runs the application
* **Amazon S3** – stores files and data
* **Amazon RDS** – manages the application's database

---

## Client B – University

**Recommended Platform: Microsoft Azure**

Azure is the best choice because the university already uses **Windows Server, Microsoft 365, and Active Directory**. Azure works well with Microsoft technologies, making migration easier and reducing compatibility problems. It also provides tools for managing users, applications, and cloud resources.

**Possible services:**

* **Azure Virtual Machines** – runs Windows-based systems
* **Azure SQL Database** – manages databases
* **Microsoft Entra ID** – manages users and access

---

## Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

GCP is a strong choice because the company focuses on **Artificial Intelligence and Machine Learning**. Google provides powerful AI and data services that can support high-performance computing and research. GCP is also well known for its data analytics and machine learning tools.

**Possible services:**

* **Vertex AI** – develops and manages AI/ML models
* **Compute Engine** – provides high-performance computing
* **BigQuery** – analyzes large datasets

---

## Client D – Global E-Commerce Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is a good choice because the company serves customers around the world and needs highly available and scalable infrastructure. AWS has a large global infrastructure that can support applications in different regions. It can also handle increases in traffic during busy periods.

**Possible services:**

* **Amazon EC2** – runs the e-commerce application
* **Amazon S3** – stores product images and files
* **Amazon RDS** – manages customer and product databases
* **Amazon CloudFront** – delivers website content quickly to users worldwide
