# Laboratory Activity 1 – Mission 1: Welcome to the Cloud

## Mission Overview

This activity introduced me to my role as a **Junior Cloud Infrastructure Engineer Trainee** at CloudNova Technologies. I worked in a Linux environment, practiced basic system administration, and created a version-controlled portfolio using GitHub.

## Objectives

* Access and navigate a cloud-based Linux environment using KillerCoda
* Gather basic system information
* Manage files and directories using Linux commands
* Create and organize a professional GitHub repository
* Document technical work using Markdown

## Activities Performed

* Launched an Ubuntu Linux Playground on KillerCoda
* Created a user with sudo privileges
* Checked the username, directory, and hostname
* Collected basic system information
* Created and organized folders and Markdown files
* Set up a Cloud Computing Portfolio on GitHub
* Documented the completed laboratory activity

`whoami`, `pwd`, `hostname`, `cat`, `uname`, `lscpu`, `free`, `df`, `mkdir`, `nano`, `ls`, `git clone`, `git add`, `git commit`, `git push`
