# Laboratory 05: Cloud Data Engineer

## Mission Overview

In this mission I acted as a cloud data engineer for a client who needs a place to store user-uploaded images. I researched the three main types of cloud storage, then deployed a MinIO object storage server with Docker and used its web console to create a bucket and upload a file.

## Objectives

- Compare block, file, and object storage and explain why object storage suits user-uploaded images.
- Deploy a MinIO server using Docker in a KillerCoda Ubuntu Playground.
- Access the MinIO web console, create a bucket, and upload a file.
- Document the deployment steps and reflect on what I learned.

## Tools Used

- Docker
- MinIO (S3-compatible object storage)
- KillerCoda Ubuntu Playground
- Linux command line
- Git and GitHub
- Markdown

## Skills Learned

- Explaining the differences between block, file, and object storage.
- Deploying a containerized service with `docker run`, port mapping, and environment variables.
- Troubleshooting Docker image pull and container name conflict errors.
- Managing buckets and objects through a web console.
- Documenting technical work clearly in Markdown.
