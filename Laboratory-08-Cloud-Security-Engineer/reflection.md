# Mission Reflection

A host-based firewall protects a server even when the physical network perimeter has been breached because it enforces rules on the machine itself. If an attacker gets inside the network, for example through a compromised laptop or a misconfigured router, the perimeter defenses no longer matter. The firewall on the server still inspects every incoming connection and drops anything that was not explicitly allowed. In this lab, the Default Deny policy meant that only SSH and port 8080 could reach the server, so an attacker who was already on the network still could not talk to any other service. This is the idea of defense in depth: no single layer is trusted completely.

Managing open network ports is critical to reducing a server's attack surface because every open port is a running service that someone can probe, and every service may contain bugs or weak settings. Closing ports that are not needed removes entire categories of attack before they can begin. Following the Principle of Least Privilege, I only allowed SSH for administration and 8080 for the web application. Fewer open doors means less to monitor, patch, and defend, and it makes unusual traffic easier to spot.

In a real enterprise environment, leaving a database port like 3306 for MySQL open to the public internet is dangerous because attackers constantly scan the internet for exposed databases. Once found, they can try brute-force or stolen passwords, exploit known vulnerabilities, or steal, change, or delete sensitive data such as customer records. A database should normally be reachable only from the application servers that need it, through a private network or a firewall rule limited to specific IP addresses. A single exposed port could lead to a major data breach, financial loss, and damage to the company's reputation.

Overall, this mission showed me that securing a server is not complicated, but it requires careful order and planning. Allowing SSH before enabling the firewall prevented a lockout, which showed me that order matters.
