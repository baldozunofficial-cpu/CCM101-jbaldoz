


## Equivalent Infrastructure Services

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | EC2 (Elastic Compute Cloud) | Virtual Machines | Compute Engine |
| Storage | S3 (Simple Storage Service) | Blob Storage | Cloud Storage |
| Networking | VPC (Virtual Private Cloud) | Virtual Network (VNet) | VPC (Virtual Private Cloud) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**

AWS is generally considered to offer the broadest range of services, with hundreds of products spanning compute, storage, databases, machine learning, IoT, and more. It was the first major cloud provider and has had the longest time to build out its service catalog, giving it more specialized offerings than its competitors.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?**

Microsoft Azure would be the best fit for an organization built around Microsoft products. It integrates natively with tools like Active Directory, Windows Server, Microsoft 365, and .NET applications, which reduces compatibility issues and licensing complexity compared to using a different provider.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**

Google Cloud Platform is widely recognized in this space. Google originally developed Kubernetes and offers Google Kubernetes Engine (GKE) as a leading managed Kubernetes service, and its AI/ML tools (like Vertex AI) are considered some of the strongest in the industry.

**4. What similarities did you observe among the three cloud providers?**

All three providers offer equivalent core services — scalable compute instances, object/blob storage, virtual networking, and identity/access management systems. They all follow a pay-as-you-go pricing model, provide global data center regions, and support infrastructure-as-code, containers, and hybrid/multi-cloud deployments.
