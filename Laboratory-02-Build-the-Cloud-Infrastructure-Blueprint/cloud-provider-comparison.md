 # Cloud Provider Comparison



| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
 |---|---|---|---|
 | Compute | Amazon EC2 | Virtual Machines | Compute Engine |
 | Storage | Amazon S3 / EBS | Blob Storage / Managed Disks | Cloud Storage / Persistent Disk |
 | Networking | Amazon VPC | Virtual Network (VNet) | Virtual Private Cloud (VPC) |
 | Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID | Cloud IAM |



Guide Questions

1. Which cloud provider offers the broadest range of services? Explain your answer.



AWS is generally considered to offer the broadest range of cloud services. It provides hundreds of services covering areas such as computing, storage, databases, networking, artificial intelligence, machine learning, IoT, security, and analytics. Since AWS was one of the first major cloud providers, it has had more time to develop a large and diverse service portfolio.



2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?



Microsoft Azure would be the best choice for an organization that primarily uses Microsoft products. Azure integrates well with Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, and .NET applications. This integration can make it easier to manage existing systems and reduce compatibility issues.



3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?



Google Cloud Platform (GCP) is widely recognized for its strong AI, ML, and Kubernetes capabilities. Google developed Kubernetes and provides Google Kubernetes Engine (GKE), a popular managed Kubernetes service. GCP also offers advanced AI and ML tools through services such as Vertex AI.



4. What similarities did you observe among the three cloud providers?



The three cloud providers offer similar core infrastructure services, including scalable computing, cloud storage, virtual networking, and identity and access management. They also support pay-as-you-go pricing, global data center regions, containers, infrastructure-as-code, and hybrid cloud environments. Although the services may have different names and features, their basic purposes are largely equivalent.
